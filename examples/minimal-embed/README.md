# @fadebasic/example-minimal-embed

A minimal Vite app that consumes `@fadebasic/components` and
`@fadebasic/runtime-assets` — the reference for how `../dby/homepage` (and
the future tutorial platform) embed a runnable/debuggable snippet.

**Status: scaffold.** Implemented in Phase 5 of
[docs/embeddable-components-proposal.md](../../docs/embeddable-components-proposal.md).
