# @fadebasic/editor

Standalone `monaco-editor` (not the VSCode workbench) plus the Fade
language: the Monarch grammar and the LSP providers (completion, hover,
signature help, references, definition, diagnostics, semantic tokens),
wired to a `@fadebasic/runtime` instance.

**Status: scaffold.** Implemented in Phase 3 of
[docs/embeddable-components-proposal.md](../../docs/embeddable-components-proposal.md).
