# @fadebasic/runtime

DOM-free client for the FadeBasic runtime — the LSP worker, the VM iframe,
and the DAP-like debug protocol — extracted from the Playground's
`FadeRunner` and `src/debug/` adapter layer. No Monaco, no DOM.

**Status: scaffold.** Implemented in Phase 2 of
[docs/embeddable-components-proposal.md](../../docs/embeddable-components-proposal.md).
